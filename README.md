# Java Programs

Welcome to my repositor. A collection of Java programs and exercises. Each program can be added as a
standalone source file or organized into its own directory as the repository
grows.

## Getting started

> [!TIP]
> Install a Java Development Kit (JDK), then compile and run a program from the
directory containing its source file:

```sh
javac ProgramName.java
java ProgramName
```

> Replace `ProgramName` with the source file's name and the class containing its
`main` method.

>[!NOTE]
> If a program declares a package or uses multiple source files, compile and run it according to that program's package and dependencies.

## Repository status

Programs and exercises will be documented here as they are added. There is no
repository-wide build tool or test suite configured yet.
