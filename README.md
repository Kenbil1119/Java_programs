## 📋 Getting started

> [!TIP]
> Install a Java Development Kit (JDK), then compile and run a program from the
directory containing its source file:

```bash
javac <ProgramName.java>
java <ProgramName>
```

> Replace `<ProgramName>` with the source file's name and the class containing its
`<main>` method.

>[!NOTE]
> If a program declares a package or uses multiple source files, compile and run it according to that program's package and dependencies.
